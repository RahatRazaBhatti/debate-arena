# AI Debate Arena — Full Stack

Elena vs. Marcus: an evidence-driven, multi-agent AI debate, moderated by you.

This package has two parts:

```
backend/    The original AI Debate Arena engine (unchanged) + a new server.py
            that exposes it over HTTP for the web frontend.
frontend/   A new React + Vite web UI: girly-professional design,
            dark/light mode, live scoring, moderator controls.
```

**Nothing about the debate logic itself was changed.** Every file under
`backend/arena/` is exactly what you uploaded — the graph, the agents, the
scoring, the persistence. The only addition is `backend/server.py`, a thin
orchestration layer that calls the same `build_app()` / `persistence` /
`phases` functions `main.py` already used for the terminal version, just
reachable over HTTP instead of `input()`.

## 1. Run the backend

```bash
cd backend
python -m venv .venv && source .venv/bin/activate   # optional but recommended
pip install -r requirements.txt
pip install fastapi uvicorn

cp .env.example .env
# edit .env and add your GROQ_API_KEY (and TAVILY_API_KEY if you want live
# web search evidence). Or set MODEL_PROVIDER=offline in .env to try it
# with no API keys at all, using the built-in mock LLM.

uvicorn server:app --reload --port 8000
```

The API is now live at `http://localhost:8000`. Interactive docs (auto-
generated by FastAPI) are at `http://localhost:8000/docs`.

The original terminal app still works exactly as before, untouched:
```bash
python main.py            # start a new debate in the terminal
python main.py --history  # list saved debates
```

## 2. Run the frontend

In a second terminal:

```bash
cd frontend
npm install
npm run dev
```

Open `http://localhost:3000`. The dev server proxies `/api/*` requests to
`http://localhost:8000` (see `frontend/vite.config.js`) — so both pieces
need to be running.

## 3. Using it

- **Start a debate**: enter a topic (or pick a sample one) and hit "Start
  the Debate." Elena opens.
- **Moderate**: after each turn, choose Continue, Challenge Elena/Marcus,
  Request Evidence, Request Rebuttal, Ask Clarification, Expose
  Contradiction, End Debate — or type a free-form challenge. This maps
  1:1 to the same moderator menu the terminal version offers.
- **Stats**: the composite score (decides the winner), evidence grounding,
  AI judge score, and momentum/activity score update live for both agents,
  with a phase/turn progress bar.
- **History**: past and in-progress debates are listed in the sidebar
  (backed by the same `data/debates/*.json` autosave files the terminal
  version writes). Selecting an unfinished one resumes it live; a finished
  one opens read-only with its final summary.
- **Theme**: toggle light/dark mode in the header — the choice is saved
  and respected on reload.

## Design

The frontend follows the brief: a "girly professional" palette (blush
pink `#d4537e`, deep teal `#0f6e56`, a touch of plum `#7f77dd`), Playfair
Display for headings, Poppins for UI labels, Inter for body text, and a
full dark-mode variable set — all defined in `frontend/src/global.css`.

## Deploying for real use

For anything beyond local development, put the FastAPI backend behind a
production ASGI setup (e.g. `uvicorn` behind `gunicorn`, or a platform
like Render/Fly/Railway), build the frontend with `npm run build`, and
serve the resulting `frontend/dist` as static files — pointing its API
calls at your deployed backend's real URL instead of the Vite dev proxy.
