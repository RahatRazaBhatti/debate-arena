SOURCE: Microsoft Research
TITLE: The Impact of AI on Developer Productivity: Evidence from GitHub Copilot
AUTHOR/ORGANIZATION: Microsoft Research (Peng, Kalliamvakou, Cihon, Demirer)
DATE: 2023
URL: https://arxiv.org/abs/2302.06590
TOPIC: AI coding assistants, developer productivity, controlled experiment

CONTENT:
Researchers ran a controlled experiment in which professional software
developers were asked to build an HTTP server in JavaScript as quickly
as they could. One group had access to GitHub Copilot, an AI pair
programmer that suggests code completions inline; the other group
worked without it.

The group using Copilot finished the task 55.8% faster on average than
the group working unassisted. The study also found signs that the
productivity benefit was largest for developers who were newer to
professional software development, suggesting AI pair programmers may
help lower the barrier to entry into the field rather than only
benefiting already-experienced engineers.

The authors caution that this was a single, bounded, well-specified
coding task rather than the messy, open-ended work that makes up much
of real-world software engineering (unclear requirements, legacy
codebases, cross-team coordination). They frame the result as evidence
that AI tools can meaningfully speed up well-defined implementation
work, not as a general claim that AI replaces the broader job of being
a software developer.

RELEVANCE: Supports the case that AI assistance measurably increases
developer productivity on concrete coding tasks (pro-AI / augmentation
evidence).
