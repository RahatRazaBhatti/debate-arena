SOURCE: arXiv
TITLE: Comparing AI Coding Agents: A Task-Stratified Analysis of Pull Request Acceptance
AUTHOR/ORGANIZATION: Independent researchers (arXiv preprint)
DATE: 2025-2026
URL: https://arxiv.org/pdf/2602.08915
TOPIC: AI-assisted software engineering, code generation agents, empirical studies comparing AI-assisted and traditional development

CONTENT:
This paper tracks how AI-assisted software engineering has moved beyond
simple inline code completion (like early GitHub Copilot) toward more
autonomous "coding agents" that can plan and execute multi-step
engineering tasks with less human direction. It documents a fast-moving
capability trajectory on the SWE-bench benchmark, a test suite built from
real GitHub issues: Devin, an early autonomous coding agent released by
Cognition AI in March 2024, solved about 13.9% of benchmark tasks
unassisted, itself a large jump over the roughly 2% state-of-the-art
that had existed just before it. By 2025, tools such as Cursor and
Anthropic's Claude Code had become widely used agentic coding tools, with
Cursor alone reportedly surpassing one million users.

The paper is explicit that raw productivity claims in this space are
mixed depending on methodology: it cites the same Peng et al. 2023
result used elsewhere in this debate's evidence base (Copilot users
55.8% faster on a bounded task) alongside the METR 2025 finding that
experienced developers were 19% slower on complex, familiar codebases
despite believing they were faster. It also cites Yetistiren et al.'s
finding that only about 28.7% of Copilot's code suggestions were directly
usable without modification on a standardized benchmark, underscoring
that "AI can attempt the task" and "AI reliably produces a correct,
ready-to-merge result" are two different claims.

RELEVANCE: Supports the "AI-assisted software engineering" pro-AI
category by documenting real, fast capability growth in AI coding
agents, while directly acknowledging (rather than hiding) the mixed
productivity evidence and low usable-suggestion rates found elsewhere in
the literature - useful for either side of the debate.
